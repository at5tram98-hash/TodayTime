# TodayTime Pro

今日・明日・最大7日間の予定とTodo、実行時間の記録、大学の課題をひとつにまとめた、ネイティブアプリのように動くWebアプリ（PWA）です。

公開URL: https://at5tram98-hash.github.io/TodayTime/
旧バージョン（読み取り用に保存）: https://at5tram98-hash.github.io/TodayTime/legacy/

## 主な機能

| 画面 | できること |
| --- | --- |
| 今日 | 現在時刻、実行中タイマー、今日の進捗・残りの空き時間・記録時間、いま／次の予定、やること、期限が近い課題、タイムライン、明日のプレビュー、遅延時の調整案 |
| 予定 | 日（ドラッグで移動・下端で長さ変更・空き枠タップで追加・左右スワイプで日付移動）／週／月、重なりの検出、移動時間の表示、アルバイトの月間勤務・給与見込み、空き時間へのタスク自動配置 |
| タスク | 自然文での追加（例: `レポート 金曜まで 2時間 !!`）、優先度・締切・見積もり・アイコン・カテゴリ・繰り返し・サブタスク、右スワイプで完了、左スワイプで明日へ／削除、長押しメニュー、検索・カテゴリ絞り込み |
| 大学 | 時間割（授業は予定に自動表示）、課題一覧、Moodle連携、単位の集計、学期と時限の設定 |
| 設定 | 外観（自動／ライト／ダーク）、文字サイズ、1日の活動時間、通知、自動調整、カテゴリ（時給）、テンプレート、実行記録と統計、バックアップ・復元・旧版からの移行 |

### 時間計測
経過時間は「開始・一時停止の時刻の記録（セグメント）」から毎回計算します。再読み込み・アプリの切り替え・端末のスリープ後も正しい値に戻ります。同時に動くタイマーは1つで、別の作業を始めると前の作業は自動で一時停止します。止め忘れ（8時間超）は終了時刻を修正できます。

### 自動時間調整
作業が予定より延びたとき、または予定したタスクの開始時刻を過ぎたときに「調整案」を表示します。

- 固定の予定（授業・「固定」にした予定）は絶対に動かしません。
- 柔軟な予定（時間を決めたタスク・「柔軟」にした予定）だけを後ろへずらし、固定予定は飛び越えて空き時間に入れます。
- 今日に入りきらない場合は明日の空き時間を提案します。締切が今日・優先度の高いものから先に今日の時間を確保します。
- 変更ごとに理由を表示し、適用後は「取り消す」で元に戻せます。履歴は設定から確認できます。

### 所要時間の予測
完了したタスクの「見積もり」と「実績」の比率（中央値）から、似たタスク → 同じカテゴリ → 全体の順に予測します。

### Moodle連携
Moodleの「カレンダーをエクスポート」で得られるiCal URL（学生が自分で取得可能）を使います。

- 課題の締切を取得し、タスクとして登録します（UIDで重複を防止）。
- 締切やタイトルの変更を検知して更新し、「Moodle 更新」と表示します。Moodleから消えた課題は削除せず残します。
- 最終同期日時・エラー内容を表示します。

**制約:** 多くの大学のMoodleはブラウザからの直接取得（CORS）を許可していません。その場合はURLをSafariで開いて .ics をダウンロードし、「ファイル」から読み込んでください（何度読み込んでも重複しません）。Moodle Web Service API は管理者発行のトークンが必要で、CORSも許可されないため採用していません。

### 通知
アプリを開いている間（または直前まで開いていた間）に、予定の開始前・締切前・期限切れ・予定の重なり・休憩のすすめを通知します。**アプリを閉じた状態では通知できません**（プッシュサーバーが必要なため）。確実に知らせたい予定は「設定 → カレンダーに書き出す」でアラーム付き .ics を端末のカレンダーへ追加してください。iPhoneではホーム画面に追加したアプリでのみ通知を許可できます（iOS 16.4以降）。

### データ
- 保存先はこの端末のブラウザ内（IndexedDB）＋予備コピー（localStorage）。**他の端末とは同期しません。**
- 1日1回と復元・移行の直前に自動バックアップ（最大14件）。本体が壊れていた場合は自動バックアップから復元します。
- JSONで書き出し・読み込み可能。旧TodayTimeのデータ（`todaytime:v2:main`）は初回起動時に自動で移行し、旧データは削除しません。

### ネイティブらしさのための対策
ピンチ／ダブルタップのズーム、UI上の文字選択と長押しのコールアウト、ブラウザのコンテキストメニュー、ページ全体のバウンス、横スクロール、入力時の自動ズーム（16px未満の入力欄）を抑制しています。入力欄・メモ・詳細のテキストは選択できます。ズームの代わりに「設定 → 文字サイズ」で拡大でき、「視差効果を減らす」「コントラストを上げる」の設定にも従います。

## 構成

ビルド不要のES Modules（GitHub Pagesでそのまま配信）。UIは同梱のPreact + htm（`src/vendor/`、MITライセンス）。

```
index.html            エントリ（テーマの先読み）
sw.js                 オフライン用Service Worker（tools/stamp-sw.mjs が生成するプリキャッシュ）
src/core/             純粋なロジック（テスト対象）
  model.js            スキーマv3・正規化
  time.js             日付・時刻
  recurrence.js       繰り返し・授業の展開
  schedule.js         タイムライン・重なり・空き時間
  tracker.js          時間計測（セグメント方式）
  reflow.js           自動時間調整
  predict.js          所要時間予測
  parse.js            自然文クイック入力
  ics.js              iCalendar読み書き
  migrate.js          旧バージョンからの移行
src/data/             永続化（IndexedDB・バックアップ）、ストア（Undo）、操作
src/services/         通知、Moodle、書き出し
src/ui/               画面・コンポーネント・ジェスチャー・シート
src/styles/app.css    デザイントークン（ライト／ダーク）とスタイル
legacy/               旧バージョン（そのまま保存）
tests/unit/           node:test によるユニットテスト
tests/e2e/            Playwright（Chromium・iPhone 13サイズ）による操作テスト
```

## 開発

```sh
npm test                 # ユニットテスト
npm run test:e2e         # 実ブラウザの操作テスト（Playwright が必要）
npm run serve            # http://localhost:4173/TodayTime/
node tools/stamp-sw.mjs  # アプリのファイルを変更したら実行（SWのキャッシュ更新）
```
